# hashcards-demo (archived)

This was the sample collection for the first version of hashcards, in a card format that 1.0 no longer uses.

**Start from [hashcards-starter](https://github.com/danielmeint/hashcards-starter) instead.** It is a template repository with sample decks in the current format, and the same decks power the no-sign-in demo at [hashcards.dev/#demo](https://hashcards.dev/#demo).
